# Knowledge Base

This directory holds durable domain knowledge that should outlive one Change but does not belong in the product vision, strategy, architecture, or an ADR. Add focused, source-grounded notes and keep decisions in `docs/decisions/`.

Loaf indexes this directory as the `metacord-knowledge` collection. Operational tasks, plans, reports, findings, and journal continuity belong in Loaf's SQLite state rather than ad hoc Markdown files here.
